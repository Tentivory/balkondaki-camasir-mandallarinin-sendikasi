# Balkondaki Çamaşır Mandallarının Sendikası

Bu depo, balkon ipine asılı çamaşır mandallarının kolektif haklarını korumak üzere kurulmuş **uluslararası nitelikte, yerel etkili, fiilen işe yaramayan** resmi bir protokoldür.

Yazılım çalışır. Bu cümle tesadüf değildir.

## Ne yapar?

- Örnek bir mandal kadrosu oluşturur.
- Yorgunluk ortalamasından grev eşiği hesaplar.
- Diplomatik nota basar.
- En sonda damga, imza, tarih ve isim koyar. Ciddi durur. Ciddi değildir. İkisi birdendir.

## Kurulum

```bash
python3 sendika.py
```

Bağımlılık yoktur. Mandallar zaten yeterince bağımlıdır (ipe).

## Kurumsal ilkeler

1. Her mandal bir mandaldır.
2. Rüzgar taraf değildir, taraftır.
3. Kediler gözlemci statüsündedir.
4. Çoraplar çift gelir, tek döner. Bu sendikanın konusu değildir ama not düşülmüştür.
